# 战斗修复与垃圾袋优化

本批次按用户最新规则统一验收后部署，覆盖早期记录中已经被修改的锤子规则。

- 限时永恒锤：15个超级碎片兑换，独立计时1小时，离线照算、不返还，不能作为超凡锤材料。
- 超凡锤：10个永恒碎片兑换，被夺返9；旧记录按实际投入减1返还。首保15小时，每次递减1小时，最低1小时。锤子计入账号跨两处泰坦合计5份超凡上限。
- 永恒与超凡锤闪电伤害降低一半；超凡花瓣包括花粉的成长数值限制在同种永恒的1.5倍内。
- S怪生命减半、20次独立掉落；正常地图增加最多8只高威胁区S怪，死亡30秒补充，不替换存活怪。取消S首领血条及出现、击杀全服播报。
- E怪生命为旧线上2倍；H怪生命为旧线上6倍、伤害及护甲2倍，经验与掉率不变，有效伤害可获得战利品资格。
- 工厂和电脑各固定一台永恒转换机，不占自然高阶怪名额；显示下一配方和轮换时间，补全齿轮加20碎片兑换同阶锯片。
- 缩小野怪外观和碰撞尺寸，保持质量；限制豌豆连发积累异常击飞，修复Wax挤怪及蛋类跨薄墙孵化。
- 补齐胡蜂发射弹药、丛林蜈蚣身体；白蚁丘按地图和稀有度限制堆积，保留内部有玩家的入口。
- 垃圾袋恢复参考项目原始袋身SVG，所有内容物分排显示、透明度0.58并保持稳定姿态，袋口及前沿包裹。内容种类、随机种子与掉落规则不变。
- 蛛网复用绘制缓存；移动端完整帧上屏，减少黑白闪屏。骰子装备栏显示服务端真实1至6点结果，首页增加GitHub链接。
- 商店统一价格乘1.75；锁定和批量购买使用相同价格计算。
- 部署停服备份校验后，定向解除Hzl的大丽花及Ygg超凡，并清除用户指定的三把超凡锤，不返还材料。操作保留幂等记录，避免重复部署误删新物品。
