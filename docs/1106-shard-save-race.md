# 2026-11-06 分服保存顺序修复（已验收候选，未重新上线）

用户明确：WebSocket断线图属于分服时期，当前单服没有问题。本轮不修改正式服务。

## 原因和修复

`GameServer::releaseUnusedAuthority`复用旧的保存确认代次。等待保存期间，断线等事件仍可写入新的进度；旧代次确认后便释放账号占用，新进度随后提交被拒绝。这能复现线上`account not exclusively owned`链路，不能简单归因于网络或锁太重，也不能用放宽独占检查解决。

原生复现先提交10、等待时改为20：旧逻辑已释放占用但数据库仍dirty，提交值仍为10，两条断言失败。修复只增加释放前捕获进度并更新确认代次，共6行，独占和持久化校验不变。
