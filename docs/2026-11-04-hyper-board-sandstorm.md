# 全服超凡持有榜与沙漠沙暴数量（2026-11-04）

## 功能

- 原排行榜新增“等级榜 / 超凡持有”页签。H页每行展示总H、玩家、花瓣名称、该花瓣数量；按持有总数降序，再按账号名和花瓣排序。刷新按钮重新取权威数据，每页100条，可前后翻页，页数按全部记录计算，不受原等级榜前50名限制。
- H榜包括在线/离线账号和管理员，不受等级榜“显示管理员”开关过滤。仅发送公开名称、花瓣及数量，不发送账号ID或认证字段。
- 数据按服务端内部背包＋已装备H统计，预设不计；两处泰坦的当前持有权按花瓣取最大值补齐，不与实体重复相加。已解除的空owner历史不计。过期的临时H锤扣除1份，仅计算，不因查看榜单修改存档。现有背包/装备变更直接写权威PlayerRecord，故无需强制保存在线玩家。
- 请求追加H偏移量，响应追加H分页数据。协议88升89，部署必须两端一起更新；本次未重建dist、未部署。
- 沙漠30个普通刷新区 sandstorm 权重0.125→0.25；两处含sandstorm:1的高权重区域保留原样。总密度、稀有度难度、地图结构及其他怪物权重不变。不改变其他地图。
