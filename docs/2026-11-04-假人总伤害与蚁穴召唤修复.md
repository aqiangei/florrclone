# 假人总伤害、召唤物测试与高阶蚁穴

- 假人保留原有最近十秒 DPS，并在下方增加“总伤害”。累计服务端标记为当前玩家及其召唤物造成的伤害，其他玩家不计入；停止攻击十秒后仍保留累计值，角色重新加入或假人被移除时重新统计。
- 地图假人为 NPC，旧召唤 AI 只扫描 MobTag，导致召唤物无法主动追打，只会路过时发生接触。将 NPC 假人纳入目标，并在同地图、主人视野及可达范围内保持已选中的测试目标；主人离开、目标消失或被墙挡住后恢复正常选敌。光标主动操控和跟随主人的边界继续生效。
- 高阶蚁穴被致死攻击命中后，旧波次查询排除了 Dead，导致 S 以上被高伤玩家秒杀时完全不释放伤害波次。现在蚁穴在回收前仍结算跨过的波次；其余怪物不在死亡后新增普通波次。
- 蚁穴的普通随从为低一阶，普通档保持普通；蚁后在生命首次低于 50% 时生成且仅生成一只，等级与蚁穴相同。不再把 E/H 蚁穴的全部随从一概截到 U。蚁后自己的兵蚁同样低一阶。
- 波次只排入一次。满怪时进入待生成队列，容量恢复后继续生成，不再永久丢掉本次波次；普通潜伏怪唤醒为巢穴战斗预留 128 个名额，硬上限不提高。巢穴随从不占地图自然刷新 S/E/H 的固定名额，也不被高阶数量清理误删。
- 没有网络字段或数据文件变更，协议与内容哈希保持 84 / 140049038。发布仍要求双端成对、停服最新存档本地 SHA256 备份、中文维护等待页及小游戏。

验收与发布结果待测试完成后追加。

## 后续玩家反馈合并

- 蛋类（Ant Egg、Beetle Egg 及各类自动生成的怪物蛋）召唤生物生命乘 2，伤害、数量与冷却不变；详情同步生命。拟态复制蛋也按有效蛋类型计算。木棍、花朵及其他召唤机制不叠加这个增强。
- 仅装备绷带、实际进入 Undead 濒死状态的孵化场景均加入回归。蚂蚁蛋/甲虫蛋蛋壳只有 1 生命，新增孵化前 1 秒保护，避免战斗接触立即打碎；保护后仍按正常规则破碎，不收回已孵化召唤物。
- 整屏黑白闪烁采用移动端完整帧缓冲：中间清屏和分批绘制留在离屏画布，完成后一次复制至显示画布；复制时不再无条件重设宽高。移动端关闭实际低延迟单缓冲呈现，设置界面说明完整帧显示；桌面仍使用原有直接绘制路径。触摸设备有效像素密度上限 2，控制双缓冲内存占用。
- WebKit 的真实 2D 画布测试覆盖移动端、无 OffscreenCanvas 的备用路径及桌面路径，确认中途黑/白内容不上屏，显示画布同尺寸呈现不重置；这不是对具体玩家手机 GPU 的真机复现结论，发布后仍需要实际反馈确认。
