# 重构机配方与20分钟刷新修复

- 排查发现机器只在生成时抽签，之后永久固定；世界种子固定，重启也会复现同样的初始结果。原配方表有12条，但月岩使用不存在的 `moon` 名称，另两条引用当前内容没有的 `ram`、`pentagon`，会在加载时被丢弃。
- 按用户确认，每台机器生成后20分钟随机换一次配方，排除当前配方，确保发生变化。机器交互范围内有玩家时延后；玩家离开后再刷新，并从实际刷新时起重新计满20分钟。
- 通过重新生成同位置、同稀有度机器并分配新网络ID发布新配方；复用现有NPC生成消息，无新增网络布局，避免只改服务端配方而客户端持续显示旧值。
- 月岩两条配方使用本项目的 `moon_rock`。移除缺少RAM、五边形物品的两条旧配方，现有10条可完整解析，不新增没有机制和来源的物品。抽签还会排除当前机器稀有度不支持的输入或产物。
- 转换数量及扣料不变；面板补充20分钟刷新、使用时延后的说明。
- 原生服务端构建通过，4项专项测试通过：10条完整配方与月岩名称；20分钟前后边界、配方变化及网络ID变化；交互时延后及重新计时；普通至最高常规档位连续20轮均抽到可用且不同的配方。
- 本项原在独立 `codex/assembler-refresh` 分支，现已集成主分支。客户端与服务端重建后按备份流程发布，中文维护页和游戏内日志均单独列出转化机修复。
