# 树枝、分裂奖励与平板检查（未部署）

用户要求本轮只提交代码、构建产物和中文记录，不部署。线上仍为 `cpp-20261103-hyper82`，本轮不启维护、不改线上存档。

## 代码修改

- 普通树枝原本已有不可摧毁配置；魔法树枝补充 `invulnerable: true`。保留展开行为、耗蓝、每次双召唤及20秒持续时间，不扩大召唤上限。现有花瓣信息按共享配置显示不可破坏。
- 灵魂分裂的两个身体共享连接。原结算刷新逻辑会把贡献记录换成查询到的第一个身体，可能读取另一个身体的配装／魔法球转换档位。现在优先保留仍存活的实际贡献身体；身体死亡或移除后，才查找同连接的存活身体。连接级伤害合并和每人一份奖励规则不变。
- 新增回归：同连接两身体的贡献合并、奖励保留最后贡献身体、身体死亡／移除后的恢复，以及两种树枝的实际加载配置都不可摧毁。此修改修正一处可确认的归属错误，不将所有“偶尔无掉落”反馈都归为同一原因。
- 游戏内中文日志和下一批维护说明同步记录，开屏自动公告继续关闭。

## iPad检查

使用WebKit的iPad设备模拟完成真实画布登录：点击用户名和密码输入框、输入及提交登录包通过。横屏1024×768与竖屏768×1024切换后，画布均保持在视口内；开屏公告保持隐藏；全屏请求能够进入或给出可关闭的降级提示。键盘桥5组回归、全屏入口回归也通过。

这轮没有获得特定iPad型号、系统版本或可复现故障，因此没有猜测性更改iPad代码。模拟验证不能确认真实iPad系统键盘或Safari权限弹层表现；若玩家仍遇到问题，需要具体操作步骤及系统／浏览器版本继续定位。不能将原留言直接标为全部解决。
