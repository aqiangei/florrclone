# 永恒锻造旧价差额返还

永久永恒同种花瓣首次10个超级材料，后续每次15个。旧规则第二次25个、第三次及以后55个：第二次返还10个同种超级材料，第三次及以后每次返还40个；第三个累计返还50个，第四个累计返还90个。限时锤子5个超级碎片不变，不参加返还。

部署时设置 `FLORR_REFUND_ETERNAL_PRICE=1`，由 `scripts/deploy-with-backup.cjs` 在维护等待页生效、正常停服、本地最新存档下载并校验 SHA256 后调用离线返还程序，先生成新副本再安装。部署失败恢复原备份。补偿记录保存在账号额外字段，按已返还总数计算差额，重复执行不会重复发放。独立校验仅允许对应超级材料库存和补偿收据变化。

旧计数最多记录2次，不能用它推定第三次不存在。返还程序读取服务器永恒锻造公告中25／55的实际消耗记录识别后续锻造；计数至少2次时补足第二次10个差额。公告历史有1000条上限，已被裁剪的第三次及以后仍需要更早存档或审计记录提供依据，不能凭现存计数恢复。

验证：`node cpp/tests/eternal_refund_tests.cjs` 覆盖首次不退、第二次、第三次、第四次、重复执行、重复公告、第二次公告被截断、限时锤子排除及找不到账号时拒绝修改。部署实际返还明细保存在本地备份目录 `eternal-refund.json`，不提交玩家存档。
